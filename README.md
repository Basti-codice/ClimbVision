# ClimbVision

Lokale Computer-Vision-Anwendung zur Echtzeit-Erkennung von Kletterbewegungen und Zuordnung von Händen/Füßen zu Griffen auf einer digitalen Wandkarte.

**Status: Meilenstein M0 (Recherche & Planung) abgeschlossen – es gibt noch keine Anwendung.** Wartet auf Freigabe für M1.

- [`docs/PLAN.md`](docs/PLAN.md) – Architektur, Entscheidungen, Kontaktlogik, Registrierung, Meilensteine, Risiken, offene Fragen
- [`docs/BENCHMARKS.md`](docs/BENCHMARKS.md) – Messwerte (Cloud), veröffentlichte Werte, Schätzungen, Laptop-Benchmark-Protokoll
- [`docs/SOURCES.md`](docs/SOURCES.md) – Quellen, Versionsstände, Lizenzprüfung
- [`bench/`](bench/README.md) – Mess-Harness (kein Teil der Anwendung), auf dem Laptop reproduzierbar

Das vollständige README (Installation, Pixel-Webcam, Offline-Betrieb, Einschränkungen) folgt mit M1.
